# 🎨 ComicCraft-AI - AI Comic Generator

### Vettri Payirchi Thittam (Naan Mudhalvan) Project

#### 📖 Project Description:
ComicCraft-AI is an innovative AI-powered comic story creator built with Google Gemini models and Streamlit. This project transforms simple story ideas into complete multi-panel comic books with AI-generated images, captions, and dialogues. It supports multiple languages including English, Tamil, and Hindi to make storytelling accessible to everyone.

#### ✨ Key Features:
* **AI Story Script Generation:** Uses Gemini 2.5 Flash to generate creative comic scripts
* **AI Panel Image Generation:** Uses Gemini Flash Image model to create consistent characters and scenes
* **Multiple Genres Support:** Adventure, Comedy, Horror, Sci-Fi, Romance, Fantasy
* **Custom Art Styles:** Cartoon, Anime, Realistic, Chibi, Superhero
* **Multi-language Support:** Dialogue generation in Tamil, English, Hindi
* **Consistent Characters:** Maintains character appearance across all panels
* **PDF Export:** Download final comic as PDF

#### 🛠️ Tech Stack:
* **Frontend:** Streamlit
* **AI Models:** Google Generative AI (Gemini 2.5 Flash, Gemini Flash Image)
* **Libraries:** Pillow (PIL), Python-dotenv
* **Language:** Python 3.9+

#### 🚀 How to Run the Project:
1.  Clone the repository: `git clone https://github.com/[Your-Username]/ComicCraft-AI.git`
2.  Install dependencies: `pip install -r requirements.txt`
3.  Set your API Key: Create `.env` file and add `GEMINI_API_KEY=your_api_key`
4.  Run the app: `streamlit run app.py`
